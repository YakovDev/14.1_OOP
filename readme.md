# Проект: Управление категориями и товарами (ООП)

Данный проект представляет собой базовую реализацию объектно-ориентированной модели интернет-магазина на Python. В нем реализованы классы для управления товарами и их категориями.

## 📋 Описание классов

Проект состоит из двух основных сущностей, расположенных в файле `src/Classes.py`:

### 1. Класс `Product` (Товар)
Описывает отдельный товар в магазине.
*   **Атрибуты:**
    *   `name` (str) — название товара.
    *   `description` (str) — описание товара.
    *   `price` (float | int) — цена товара.
    *   `quantity` (int) — количество товара на складе.

### 2. Класс `Category` (Категория)
Группирует в себе товары и предоставляет методы для подсчета статистики.
*   **Атрибуты:**
    *   `name` (str) — название категории.
    *   `description` (str) — описание категории.
    *   `products` (list[Product]) — список товаров в категории.
*   **Методы:**
    *   `product_count()` — возвращает количество уникальных позиций товаров в категории.
    *   `category_count()` — возвращает общую сумму всех единиц товара (сумма `quantity` всех продуктов) в категории.

## 🚀 Установка и запуск

Проект использует Poetry для управления зависимостями.

1. Установите зависимости:
   ```bash
   poetry install
   ```

2. Запустите основной скрипт (находится в корне проекта):
   ```bash
   poetry run python main.py
   ```

## 🧪 Тестирование и покрытие (Coverage)

В проекте настроено тестирование с помощью `pytest` и замер покрытия с помощью `coverage.py`.

Для запуска тестов выполните:
```bash
poetry run pytest
```

Для генерации отчета о покрытии:
```bash
poetry run coverage run -m pytest
poetry run coverage report
```
